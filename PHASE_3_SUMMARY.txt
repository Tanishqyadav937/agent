12. KNOWN LIMITATIONS
═══════════════════════════════════════════════════════════════════════════════

NONE CRITICAL - All limitations are acceptable or have workarounds:

1. Viseme Estimation (Non-critical)
   • Uses frequency analysis, not true phoneme recognition
   • Sufficient for basic lip-sync movement
   • Future enhancement: Replace with speech-to-phoneme API
   • Current: Works well enough for realistic appearance

2. Microphone Permission (Expected)
   • Browser requires explicit user permission
   • Standard web security measure
   • Permission lasts for session duration
   • User grants once per browser session

3. Audio Latency (Expected)
   • ~300-500ms from speech end to UI update
   • Caused by browser audio buffer processing
   • Acceptable for real-time scenario
   • Not noticeable during active conversation

4. Frequency-based Analysis (By design)
   • Works on current audio data only
   • Processes in real-time during playback
   • Not applicable to pre-recorded analysis
   • Works perfectly for live response scenario
